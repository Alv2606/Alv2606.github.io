# Panadería La Alhambra — Sitio estático

Pequeña página web estática de ejemplo para una panadería que produce dulces típicos de Granada.

Archivos principales:

- `index.html` — Página principal en español.
- `styles.css` — Estilos base responsive.
- `script.js` — Interacciones (menú móvil, formulario simulado).
- `assets/logo.svg` — Logo simple en SVG.

Cómo abrir localmente:

1. Abrir `index.html` en un navegador (doble clic) o
2. Levantar un servidor local (recomendado). Por ejemplo, con Python 3:

```powershell
python -m http.server 8000
# luego abrir http://localhost:8000/
```

Personalización rápida:

- Cambia el texto y las imágenes en `index.html`.
- Modifica colores en `styles.css` (variables CSS en :root).
- Actualiza el logo en `assets/logo.svg`.
